id: hydra
keys: hydra, summon, slash command, catalog alias
---

summon path : the agent posts the selected catalog model only after local search misses.

model command : /model prints the numbered picker. /model <number> or /model <alias> sets the brain.

alice brain : /model alice searches written skills and alice_core.js. /summon sets the inference alias used on a gap.

direct brain : any other catalog alias posts that alias on the next turn.

refusal : an alias absent from the catalog is refused. the provider never receives an unregistered string.
